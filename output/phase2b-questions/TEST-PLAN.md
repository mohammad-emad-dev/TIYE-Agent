## Composition

Use only the existing fixed owned core host, witness, private-root allocator and
process helper. The fixed report/question host selects coder/Leader/owner handles
in coordinator code; wire DTOs cannot choose an actor, handle or executable.
No provider, UI, network/MCP, credentials, real project/Git/export operation or
new runner. Native runtime remains pinned Windows x64 Node26.7.0/modules147 and
installed better-sqlite3 prebuild/dependency files, measured and hashed in preflight.

Schema4 uses exact schema3 tables plus
`CREATE TABLE questions (id TEXT PRIMARY KEY, value TEXT NOT NULL) STRICT`.
Its explicit create/open factories refuse older schemas. Schemas1-3 retain original
operation semantics. There is no migration, repair, import or read-only fallback.
All materialized questions/tasks and derived reservations rebuild independently
from canonical events and compare against storage on open; no reset follows drift.

The command DTO/hash rules are the frozen CONTRACT.md section3. Actual codecs
validate exact fields, canonical compact UTF-8 <=16KiB, UUID-v4, version1, existing
Unicode text limits and0-3 distinct options. Answer union has exactly one variant;
unsafe indices/malformed shapes refuse before admission, valid out-of-list indices
reject semantically. Shared ledger binds type/actor/version/all payload and checks
exact retries before state, capacity or recovery fence. Questions are not tasks.

Ask accepts matching member, active session, nonclosed started assignment with
planned/completed effect, no earlier accepted question on that assignment and
fewer than20 accepted questions total. Non-Leader routes Leader; Leader routes
owner. Escalation once transfers that same question to owner without a Leader task.
Current recipient alone answers. Visible detached history follows the contract
matrix and omits internal question counters. All sequence bindings derive from
actual global accepted events, including shared stop sequence.

Opening blocks the task and retains assignment slot/budget. Both API and replay
gate raw mutations; semantic reports reject. True no-ops/rejected commands and
past ledger decisions cannot execute or change the question. Answer restores only
waiting_approval/running based on actual effect/approval; completed means report-only.
Stop cancels questions in its existing composite event, removes blocked overlays
and applies unchanged task/effect stop rules. Recovery leaves pending questions
blocked; its new-write fence covers questions/owner answers until acknowledgement.

Capacity is events + assignment units + question units + legacy reserves + active
stop reserve <=1000. Ask spends one new event AND holds two separate question units;
it never borrows terminal/stop capacity. Escalation spends1; answer spends1 then
releases leftover; stop spends global1 and releases question budgets. Rejected
traffic cannot spend held units. Limits count accepted lifetime history, including
answered/cancelled records. No reopening recreates units or reuses the sole attempt.
