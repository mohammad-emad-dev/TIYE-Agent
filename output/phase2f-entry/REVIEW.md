# Owned-worker proposal review

27 October 2026. Parent inspected current core process restrictions, fixed witness
schema/action, owned-child test helper and accepted failure/stop/reconciliation
semantics before choosing a separate private execution harness. No new controller,

## Parent decisions and clarifications

The core remains synchronous and free of process-launch imports. One reviewed Node
worker script receives no engine database path or privileged role, and can perform
only the fixed witness append in its owned disposable target. Controller limits
two live workers/six assignments; all paths/modes/environment/source files must be
pinned in actual preflight. No new schema is needed for this composition step.

Ready grants no action. Approval remains an explicit fixture decision. Claim must
commit before one-time wire delivery; backpressure/lost reply cannot justify resend.
Success waits for worker exit, complete transcript validation and one matching
independent witness row. A worker's done prose cannot release occupancy. Failure
proof is observed after verified exit but resolution/abandonment remains explicit.

The parent tightened the initial contract in three places before finalizing:

1. A post-claim observation retains uncertainty only while the effect is still
   dispatching/uncertain; already settled outcomes keep the existing core table.
2. Storage errors are not worker crashes. Freeze dispatch, clean up owned workers,
   surface the actual durable state and require explicit fixture inspection/exact
   command redelivery. A committed settlement/report/observation with a lost reply
   remains valid; no invented replacement failure or second claim is allowed.
3. Normal accepted stop commits before interruption. If stop persistence fails,
   owned-worker error cleanup must still occur within bounds, but cannot be called
   an accepted stop or treated as cancellation/absence of an effect. Local dispatch
   stays fenced while core history awaits explicit recovery.

Intentional stop does not automatically become a crash notice. Late results cannot
turn interrupted work done, and a done report committed before stop remains stable.
Controller/whole-host crash survivor management is explicitly excluded; this slice
never adopts persisted PIDs or guesses that a writer is gone. New reachability is
limited to the fixed synthetic action, with its required reviewed process checks.
