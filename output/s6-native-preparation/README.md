## Verification and publication

```powershell
rtk proxy python -B -X utf8 feasibility/s6-wsl/native-preparation/run.py
rtk proxy python -B -X utf8 -m unittest discover -s feasibility/s6-wsl/native-preparation -p test_preparation.py -v
```

The checker requires Python 3.12 or newer and reads only fixed repository inputs
and their saved source references.
It checks saved installation/candidate agreement and exact public package shape,
rejects duplicates and path escapes, refuses links/junctions and native flags, and
never launches a subprocess. Eight offline tests include altered admission,
cross-cohort credit, candidate/hash changes, private-field injection, malformed
paths and actual source/installation mutations in a disposable copied fixture.
No new live lifecycle test was needed for this preparation step.

No new raw runtime capture was produced. Actual executable/account locations and
historical raw outputs are not copied into this public package; original evidence
locations remain as recorded. Existing historical public artifacts may already
contain machine paths; this index does not retroactively make them private.
File hashes detect snapshot changes, not a malicious editor changing checker and
manifest together. Repository integrity is a trust assumption. Link checks are
not hostile-filesystem race protection. Any input/route/environment/source change
requires a new review; matching hashes alone never grants admission.

GPT-6 Luna max and GLM-5.3-Flash Free max supplied reply-only risk reviews. Neither
reviewed final source or ran tests. We adopted evidence separation, private-field
refusal and precise intent/measurement labels. We did not adopt an unsupported
clock dependency or a redundant mode-000 matrix: neither resolves a current gate.
